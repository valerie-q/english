Choose the correct option — with or without article/some.

  1. Most of my friends are students / some students. (students is correct — given example)
  2. Are you careful driver / a careful driver?
  3. I went to the library and borrowed books / some books.
  4. Mark works in a bookshop. He sells books / some books.
  5. I've been walking for hours. I've got sore feet / some sore feet.
  6. I don't feel very well. I've got sore throat / a sore throat.
  7. What lovely present / a lovely present! Thank you very much.
  8. I met students / some students in a cafe yesterday. They were from China.
  9. It might rain. Don't go out without umbrella / without an umbrella.
  10. People / Some people learn languages more easily than others.
Answer key
  1. students (given)
  2. a careful driver
  3. some books
  4. books (general — what he sells)
  5. sore feet
  6. a sore throat
  7. a lovely present
  8. some students
  9. without an umbrella
  10. Some people
Загальне правило: якщо іменник countable singular — завжди потрібен a/an (a car, an idea, a game). Якщо countable plural — можна без артикля (books, students) або з some коли йдеться про невизначену кількість (some books — конкретні кілька штук). Якщо uncountable (music, blood, patience) — ніколи не використовуємо a/an.

Grammar box — Saying something exists BP p.23
Коли використовуємо There is / There are?

Ми використовуємо there is / there are коли хочемо сказати що щось існує або є в наявності — тобто коли вперше згадуємо щось або говоримо про кількість.

There is → одна річ (singular):
There is a problem with your order. — Є проблема з вашим замовленням.
There's a kitchen on the first floor. — На першому поверсі є кухня.

There are → більше однієї (plural):
There are some discounts for large orders. — Є знижки для великих замовлень.
There are two ways to return your order. — Є два способи повернути замовлення.

Порівняй з "it is":
There is — ми вперше говоримо про щось (воно існує)
It is — ми вже знаємо про що мова, уточнюємо деталі
There's a charge for delivery. It's €4.50. — Є плата за доставку. Вона становить €4.50.
THERE IS / THERE ARE
+There is (There's) a delivery charge.  ·  There are some discounts on large orders.
−There isn't a store near me.  ·  There aren't any delivery charges in the EU.
?Is there a discount? → Yes, there is. / No, there isn't.
?Are there any deliveries at the weekend? → Yes, there are. / No, there aren't.
There is + одна річ (singular)  ·  There are + більше однієї (plural)
There is a problem.  ·  There are some problems.
