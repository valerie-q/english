Speaking box — Making Agreements BP p.25
Making Agreements
Asking about the company's service
How many [workers / chefs] are there?
How about [coming] [before / after] [8 o'clock / we start work]?
Can [you / your team] do that?
How much time do you need?
Does the price include [materials / plates / cleaning products]?
When can [you / your team] start?
Asking the client questions
What do you want [the cleaner / us] to do exactly?
How many [days / hours] do you need the service?
What time do you want [the cleaner / chef] to come?
Is there a place for the [cleaning products / materials]?
How about [on Monday / on the 14th]?
Saying yes / no
Yes: Yes, we can. · Yes, it does. · Yes, that's fine. · Yes, of course. No: No, we can't. (I'm sorry). · No, it doesn't. (I'm sorry).

Exercise B — Make questions with Is there / Are there

Turn these statements into questions.

  1. There is a kitchen at the office. → ?
  2. There are vegetarian options on the menu. → ?
  3. There is a discount for large orders. → ?
  4. There are enough chairs for everyone. → ?
  5. There is a charge for delivery. → ?
  6. There are any problems with the order. → ?
Answer key
  1. Is there a kitchen at the office?
  2. Are there vegetarian options on the menu?
  3. Is there a discount for large orders?
  4. Are there enough chairs for everyone?
  5. Is there a charge for delivery?
  6. Are there any problems with the order?
✏️
Exercise C — Choose some or any
  1. Do you have some / any vegetarian sandwiches?
  2. We have some / any canapés left over from the party.
  3. There aren't some / any cake platters available today.
  4. Can I get some / any information about the delivery cost?
  5. I'd like some / any cut fruit platters for the event.
  6. Is there some / any discount if we order in bulk?
  7. We don't have some / any sandwiches without meat.
  8. Would you like some / any coffee while you wait?
Answer key
  1. any (question)
  2. some (statement)
  3. any (negative)
  4. some (polite request — sounds like offer)
  5. some (request)
  6. any (question)
  7. any (negative)
  8. some (offer)
Нагадування: any — у питаннях і заперечних реченнях. some — у стверджувальних реченнях, а також у пропозиціях і проханнях (навіть якщо це питання!): "Would you like some coffee?" — це пропозиція, тому some, не any.
